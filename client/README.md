# Magnify

Magnify is the Next.js frontend for the project-based PDF research workspace. It uses MUI for the interface and Clerk for authentication.

## Development

Requires Node.js 20.19 or later and Yarn 1.22.10.

```bash
yarn install
yarn dev
```

Open [http://localhost:3001](http://localhost:3001). Configure Clerk and the backend URL as described in [INTEGRATION.md](INTEGRATION.md).

## Checks

```bash
yarn lint
yarn build
```
